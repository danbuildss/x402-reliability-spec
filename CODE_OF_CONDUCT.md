# Code of Conduct

## The short version

Be direct. Be specific. Focus on the work.

Disagreements about spec design, stage definitions, and field semantics are expected and welcome. That's how standards improve.

Personal attacks, harassment, and dismissiveness toward contributors are not acceptable.

## What this means in practice

**Do:** Point out where the spec is ambiguous. Share real service behavior that breaks the current definition. Propose precise wording. Disagree clearly with a reason.

**Don't:** Attack people for implementing the spec differently. Mock contributions. Ignore good-faith feedback because of who sent it.

## Scope

This applies to all interactions in this repository: issues, pull requests, and comments.

## Enforcement

Violations can be reported to the maintainer via GitHub. Repeated violations result in removal from the project.
